# Atlas原生信息与ESMC条件probe：已完成

2026-09-26 05:30 HKT，DiamondHill。9/9个小头拟合完成（每个1536步，合计13,824更新），统一评分完成；没有新增folding适配训练。另完成6个ESMC Native传播观测及4次工程推理。

## 核心结论

**本轮未建立ESMC超过容量匹配原生读出的主要收益。**正确对齐的ESMC优于置乱ESMC的总体CE，但这是次要对照，不能替代它相对于原生信息的主要比较。结果与“当前设置下额外可利用收益有限”相容，不能证明ESMC完全冗余。

|输入（每个131,520个可训练参数）|最终Train96 CE|最终Dev8 CE|
|---|---:|---:|
|原生single/pair＋原生single第二视图|1.459637|1.475322|
|原生single/pair＋对齐ESMC|1.456341|1.472815|
|原生single/pair＋固定置乱ESMC|1.459194|1.477265|

CE越低越好。这些不是lDDT，也不是Atlas完整结构预测器的损失/质量；是独立小probe的64-bin距离分类交叉熵。

|预定比较（正值表示对齐ESMC更好）|Dev8均值|95%条件目标区间|三个种子均值|
|---|---:|---|---|
|**主要：原生−对齐ESMC**|+0.002506|[−0.000186,+0.005430]|−0.000573 / +0.003231 / +0.004861|
|次要：置乱ESMC−对齐ESMC|+0.004450|[+0.002639,+0.006270]|+0.001404 / +0.011780 / +0.000166|

主要比较一个种子反向，区间跨零。次要结果说明此读出对ESMC残基对应关系敏感；不构成条件互信息检验，也不说明已可靠超过原生信息。

## 具体实现与范围

- 原生输入来自完整Query-only第一轮四层LM stack末端s768/z128，包含AtlasLM多层与attention-derived pair路径，不是人为删去pair信息的末层embedding基线。
- 两种辅助源都通过固定、无标签Gaussian128维投影及无参数归一化。原生对照额外支路有真实非零输入，与ESMC两臂同参数/decoder/初始化/更新预算；并不保证各输入优化难度相同。
- 特征及PLM/主干冻结；仅训练小probe。输入不含真实结构；监督和评分单独读取原始原子映射/伪β标签。
- Train96/Dev8均为旧开发范围；3seed先聚合后按8目标bootstrap20,000次。区间条件于本9个拟合实例，不能充当新盲确认或完整重训练置信度。
- 固定0/384/768/1536节点，最终1536唯一报告终点，不依曲线选模型。没有追加学习率、层、宽度或目标搜索。
- 固定压缩、归一化、小头容量及有限数据可能限制收益。阴性不能证明全部ESMC信息被AtlasLM覆盖，阳性也不会自动解释folding适配为何无收益。
