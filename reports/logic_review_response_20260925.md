# Fresh192与补偿重复：逻辑审阅落实（2026-09-25）

基于 `main@4836047`，落实[逐行逻辑审阅](logic_review_1889a69_worktree_20260925.md)，并随后核对 [review5-2](review5-2_4836047_20260925.md)、[review6-2](review6-2_4836047_20260925.md)。后两份原始意见已原样归档；它们评价的是修改前快照。本轮仅调整写作和展示，不改变实验合同、统计终点或数值来源。

## 主线与六项修改

当前主线是：**固定预算下，指定 Protenix/ESMC 配方的参数化相关旋转敏感性获得新目标支持；共享正交输出映射改善旋转臂，但相对 Native 的额外收益未在重复执行中重新建立。**

1. 摘要与引言直接提出固定训练预算下的问题，并将第二个问题具体定义为 Factor 内加入共享、可训练正交输出映射后的 Native–Rotated 分数差。
2. 主文 Table 3 合并绝对分数与原执行／重复执行的三项收益和全部区间，直接复用已有生成表：旋转臂收益约 +0.02973／+0.03025，Native 收益 +0.01290／+0.02960，额外缓解 +0.01684／+0.00065。正文解释这些点估计，统一采用 “was not re-established”；没有新增执行间差异检验，也不把后一次区间跨零写成效应为零。
3. Fresh96、Fresh192 同列于 “New-target tests of fixed recipes”，提前到两底座观察面板发现之后。旧面板的指标、种子稳健性随后报告；Train384 特征扩展合并到范围结果。Fresh192 明确是对历史数据选定固定配方的前瞻验证。两个新面板的底座、训练规模、特征和目标均不同，不构成直接底座比较。
4. 重建阴性结论限定为一个预先指定的指标和八个旋转，以 “post-training rotation penalties” 明确其对象是性能分数差，不是训练算力开销。
5. 四格到补偿的承接明确：前者比较完整参数化，后者检验 Factor 内新增输出自由度是否优先帮助旋转臂。主文交代两枚旋转来自独立八旋转预测研究、并非四格中的三枚历史旋转；吸收保证限定于保持全一方向的特殊正交子群。
6. 明确 Protenix 段落主语、每次执行九组、分别训练但配对的设计。锚点附录同步补偿重复后的结论边界。

另补显式的带符号平均量 $\Delta_H$ 定义，澄清接口基线更新与整张 pair state／公共 query-only 轨迹的区别，并将 Related work 的 Factor 闭包措辞收回到“尚无对应一般保证”。
