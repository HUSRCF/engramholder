# 候选：已学习残差的方向×幅度交叉（未锁定、未启动）

这是 v4 核对后的单一候选，不是已批准的运行队列。目的：连接“学到的残差性质”和“完整结构推理”，不声称识别训练过程或每个下游模块。

## 建议范围

- Mini / Train384 / Full / 1536，三个训练种子及三个既有旋转；使用已有最终 checkpoint。
- 24 个已经观察的 Confirm96-B 目标，按原有长度分层每层取六个确定性排序目标；最终 ID 必须在运行前写入执行锁。该集合不是新盲确认。
- 从序列与冻结模型生成残差；标签只用于最终评分，不参与范数、方向、目标或输出选择。
- 使用正式静态 query update hook，四轮均注入同一混合残差，保留 c4/s5、配对随机条件、完整序列和原评分。

## 四格

令 `δN=mN*dN`、`δR=mR*dR`（实际已部署的旋转模型残差，不能省略它原有旋转），`U=Uq+δ`。

| 格子 | 注入残差 |
|---|---|
| NN | δN |
| NR | (mR/mN) δN |
| RN | (mN/mR) δR |
| RR | δR |

对已形成的完整 pair 残差缩放；不缩放 δa/δb，因为 Full 含二次项。每个旋转与同训练种子的 Native 配对，各自交换范数，不先把三个旋转范数平均成一个更新。

范数为零时单位方向无定义。科学锁必须提前规定处理：记录为未定义干预、保留目标与完整覆盖记录，不用 epsilon 随意生成方向或悄悄删除。工程 gate 先核对完整待评集合是否存在此情况，再决定协议可执行性；不依据结构分数处理。

## 主要与次要读数

- 建议唯一主要终点为 Cα pair-lDDT 上对幅度来源对称平均的方向来源效应：`Edir=[(YNN−YRN)+(YNR−YRR)]/2`。
- 次要：`Eamp=[(YNN−YNR)+(YRN−YRR)]/2`、`I=YNN−YRN−YNR+YRR`、四格绝对分数及残差范数比；逐残基 lDDT、TM-score 为补充。
- 校验恒等式 `Edir+Eamp=YNN−YRR`，不将其称为自然因果贡献百分比。
- 同目标先聚合种子/旋转，再以目标为 bootstrap 单位。不能把 216 个种子×旋转配对作为独立蛋白。

方向来源来自独立训练的头，包含学习到的内容差异；这是来源干预，不能重新标为同一个残差的纯旋转效应。混合更新可能落在训练轨迹之外，需要保留这一解释边界。

## 工程与预算

两条固定目标先查完整 Native/Rotated 回放、实际残差范数、混合方向余弦、query baseline 不变、四次 pair-stack 调用、采样随机条件一致。无需重新做微小 loss FD。通过只说明干预实现正确，不允许根据结构效果选幅度。

混合任务数为 `24×3×3×2=432`。若旧 Native/Rotated 基线的模型、推理配置、输入和后端不足以配对复用，需要另算 `24×(3+9)=288` 次基线，合计 **720 次正式预测**，工程检查和预定重试另计。不能只宣传 432 次而默认旧 CIF 必然可复用。

全部任务在查看新质量分数之前锁定；统一记录失败并沿用原分母和失败处理。没有方向效应或混合严重退化，都按该干预范围报告，不自动扩大面板、细分 recycle 或调倍率。仅在作者明确选择该研究后实施。
