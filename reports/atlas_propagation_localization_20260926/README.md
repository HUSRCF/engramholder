# Atlas传播定位：完成与判断

2026-09-26，DiamondHill原Atlas ROCm环境完成。固定两条旧诊断链7hln_A/9qdy_A，3个Native父模型及各自C_only/head_only。20个观测实例＋6次工程重放，无新增训练。另保留首次后处理失败前的6次Query工程前向，物理执行合计32。

## 结论先行

**本次没有发现某个接口把更新整体抹掉：更新穿过LM stack和投影，影响保留到主干末端，但最终结构响应较弱。**因此，“过早注入导致进主干前就完全丢失”不符合这些案例；本次也没有证明缺少状态条件化就是原因。

父模型pair相对变化为 `RMS(Adapted−Query) / RMS(Query)`，所有分子分母在同目标、同轮、同位置比较。下列为两链×三种子×五轮的中位数，不能当作30个独立样本的区间：

|位置|同位置相对差异|绝对差RMS|Query RMS|
|---|---:|---:|---:|
|首接口加法后|36.12%|68.46|189.16|
|LM stack末端|27.94%|102.44|370.06|
|投影LayerNorm后|32.03%|0.317|0.982|
|投影完成|21.22%|2.284|10.66|
|投影与回收状态融合后|16.19%|2.323|14.78|
|主干末端|3.11%|3.159|101.29|

**不能由这张表推断“主干消除了81%的更新”。**相对分母随网络位置变化；主干输入到末端的绝对差RMS反而增大。这里可说差异相对于该位置的背景状态较小，不能说绝对信息已被删除。

LayerNorm前后裸RMS跨越很大尺度，但相对差异没有同步消失；LM末端差分中通道常量分量能量中位数仅0.210%（范围0.117–0.459%）。这不支持“主要是通道均值偏移被LayerNorm简单清除”的解释，但不构成LayerNorm作用的完整因果分解。

三个种子在两链末轮的pair相对变化仍为2.07–5.66%；single相对变化为0.756–2.62%。最终父模型对Query的Cα距离差RMS为0.0129–0.1011 Å、配准Cα RMSD为0.0171–0.1328 Å。这是同序列两次预测之间的变化，不是真实结构质量或其改善。

## 已完成通道校准必须保留

旧六组512步续训、960次预测、零失败，汇总和原始指标记录与完成收据SHA256一致；未重新评分CIF。

- C_only−head_only：−0.00000513，95% CI [−0.00069698,+0.00074909]。
- C_only−Query：−0.001287，95% CI [−0.003015,+0.000408]。

本次C_only、head_only的传播轮廓与父模型接近，主干末端pair相对差中位数分别3.30%、3.25%，父模型3.11%。这没有建立校准收益，更不是旋转交互证据；没有基于两链新诊断重新估计质量区间。

## 能决定和不能决定的下一步

- 可以排除本固定案例中的“首接口没生效/更新完全未到主干”作为主要解释。
- 目前观测呈现“内部状态有差异，最终结构变化较小”，没有定位出唯一失效层；尤其不能把裸范数变化解释成信息丢失。
- 状态条件化writer是独立的新假说。本轮代码显示LM stack独立于回收状态；这不等于加入回收状态就能提升质量。
- 首个/最后一个LM接口比较同样仍是候选。当前没有出现LM stack已把变化抹掉的证据，不据此直接优先启动晚层训练。
- 两个目标是旧观察案例，范围有限；不扩大为Atlas所有目标/模型的机制结论。保持这次定位有界，不自动启动新训练或继续扫描更多hook。
