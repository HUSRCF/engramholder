## 1. 已核对的关键实现事实

- 当前使用 `model_3_ptm`，48 个 Evoformer block，只挂**第一个 block 的 OPM**。不是改造 48 个 OPM。
- `max_recycling_iters=3` 对应初始 pass 加三次 recycle，即 **4 次完整 trunk / structure-module 执行**。以下统一用总 pass 数 $p$，不用含混的“1 recycle”。关闭提前停止、模板和 MSA 重采样。
- Factor 的两个逐残基增量由同一 PLM 特征和共享头产生；现场因子随运行状态变化。G+ 也读取相应现场因子。禁用某轮适配只能返回该轮的现场原生 OPM baseline，不能把 pair state 重置成 query-only 轨迹。
- 原训练脚本和 smoke 明确检查四轮梯度状态 `[False, False, False, True]`。**直接在原训练循环中启用 first-only，会切断最终损失到适配器的有效梯度路径。** 把 `model.train()` 打开不能代替正确处理跨轮求导。
- 当前 Factor 已在 decoder 中施加 R；旋转 G+ 已在输出施加 R。新增时序开关只控制是否使用现有残差，不能再乘一次 R。

本地依据：[运行配置](../../onestepfold/engramfold/src/engramfold/experiments/openfold_adapter_runtime.py)、[现场 OPM](../../onestepfold/engramfold/src/engramfold/models/live_opm.py)、[原训练循环](../../onestepfold/engramfold/scripts/run_openfold_study.py)、[原 smoke](../../onestepfold/engramfold/scripts/smoke_openfold_adapter.py)。冻结版本及权重身份见[单目标资产清单](../reproducibility/openfold_single/asset_manifest.json)，原四格种子／旋转见[旋转 G+ 执行锁](../reproducibility/openfold_rotation_execution_lock.json)。

官方固定提交 `be2ec1841f16c966c65ae0e7599ebbadc725757d` 的 [`AlphaFold.forward`](https://github.com/aqlaboratory/openfold/blob/be2ec1841f16c966c65ae0e7599ebbadc725757d/openfold/model/model.py#L517-L560)同样只对最后一次迭代启用梯度，并传递 MSA 首行、pair 与坐标状态。本轮是源码核对，不是新 GPU 路径已经通过的声明。

## 2. 科学问题与注入定义

固定已训练参数 θ，定义注入开关 $q_{s,t}\in\{0,1\}$：

\[
U_{s,t}=U_{0,t}(\mathrm{state}_{s,t})
       +q_{s,t}\,R\Delta U_\theta(\mathrm{state}_{s,t}).
\]

Native 取 $R=I$；公式为展示记号，实现复用原来的单次旋转位置。$U_{0,t}$ 始终是**该干预轨迹**的现场 baseline，不能误解成四条相同的 query-only 更新。

第一阶段的 θ 都是在 all 策略下训练的。改变部署策略会产生训练／推理不匹配；结果不能直接评判 first-only 或 last-only 从头训练后的适配能力。

| 四轮策略 | 注入向量 | 直接回答什么 |
|---|---|---|
| all | (1,1,1,1) | 原有部署方式的同环境回放 |
| first-only | (1,0,0,0) | 首次写入经过后续冻结 recycle 后，效果是否保留／变化 |
| last-only | (0,0,0,1) | 没有此前适配历史、也无后续 recycle 时，一次末轮写入的效果 |
| query-only | (0,0,0,0) | 同深度未适配基线 |

last-only 仍经过末轮完整 Evoformer 与结构模块，只是没有**后续跨 pass 的适配反馈**，不能称“没有下游处理”。first-only 的后续 baseline 仍受到第一次写入形成的状态影响。

与附录 T 的区别明确：T 改残差**用什么 anchor**；这里改**在哪些 pass 写入**。两者互补，但本轮不再叠加 Q-anchor 或 C，避免把问题变成更大交叉矩阵。

- 使用原训练种子 `20260923/20260924/20260925`、原核心四格旋转 `20261001/20261002/20261003`。**不换成 E1/E2/E3 的两枚保均值旋转。**
- 完整 Confirm96-B 96 条目标；不根据旧效应、质量或长度再选子集。此为已观察面板的预先规定后续干预，不是独立新目标确认。
- 固定原参数、ESM2 层／缓存、原输入 mask、单序列无模板、推理种子 `20260921`、FP32、chunk、完整长度和评分对应。推理不读取真实坐标或参考残基 mask。

### 3.2 在同一条轨迹保存第 1、2、4 轮输出

建议对三个策略全部运行四轮，观察器保存每轮完整坐标及原子 mask；分析只使用预定的 1、2、4 轮。这样获得六个适配条件：

| 总 pass 数／策略 | 实际发生的注入 | 分析角色 |
|---|---|---|
| 1 / 单次 | (1) | all 与 first-only 的共同前缀，计一次 |
| 2 / all | (1,1) | 深度与重复写入同时增加 |
| 4 / all | (1,1,1,1) | 核心回放条件 |
| 2 / first-only | (1,0) | 保持一次写入，增加后续传播 |
| 4 / first-only | (1,0,0,0) | 保持一次写入，继续传播 |
| 4 / last-only | (0,0,0,1) | 相同总深度、单次末轮写入 |

query-only 同时保存 1、2、4 轮。last-only 的前两轮应与对应 query-only 相同，不作为新的科学条件重复计数。all 与 first-only 的第 1 轮同样不能算两个独立预测实例。

**为什么加 first-only 的深度曲线：**仅观察 all 的 1→2→4，会同时改变下游计算深度与直接写入次数。first-only 的 1→2→4 保持一次直接写入，更接近“首次修改如何经冻结后续过程传播”的问题；它仍不是对某个具体反馈组件的单独干预。

这里的 1/2 轮先定义为同一四轮执行的**前缀终点**。工程阶段另验证从相同四轮特征前缀独立截停所得坐标与所保存快照一致，检查 `_recycle`、提前停止和输出头的语义；未经检查，不将其等同于随意修改某个 CLI 参数的标准单轮模式。各前缀是一套模型的相关输出，不是增加了独立蛋白样本。

## 4. 终点：检验差的变化，而不是比较显著性标签

每个条件 $s,p$ 分别报告四格绝对分数、相对同深度 Query 的适配收益，以及

\[
\Delta_F(s,p)=\overline S_F(s,p)-\overline S_{RF}(s,p),\qquad
\Delta_G(s,p)=\overline S_G(s,p)-\overline S_{RG}(s,p),
\]
\[
\Psi(s,p)=\Delta_F(s,p)-\Delta_G(s,p).
\]

每个目标内先平均三个训练种子和相应三个旋转，再聚合目标。保留种子、旋转及九个交叉单元边际；绝不能先平均残差向量再当作一个预测器。

**建议唯一主要比较：**Confirm96-B / Cα pair-lDDT 上的

\[
D_{\mathrm{write}}=\Psi(\mathrm{all},4)-\Psi(\mathrm{first},4).
\]

正值表示既有全轮训练模型在允许后续直接写入时，表现出更大的头类型×旋转交互。比较对象是两条完整策略，包含它们诱发的后续状态差异；不能唯一归因于反馈放大。

预先保留四个次要直接比较：

1. $D_{\mathrm{last}}=\Psi(\mathrm{all},4)-\Psi(\mathrm{last},4)$。
2. $D_{\mathrm{timing}}=\Psi(\mathrm{first},4)-\Psi(\mathrm{last},4)$。
3. $D_{\mathrm{prop}}=\Psi(\mathrm{first},4)-\Psi(\mathrm{single},1)$。
4. $D_{\mathrm{depth}}=\Psi(\mathrm{all},4)-\Psi(\mathrm{single},1)$。

有一个便于核对和展示的恒等式：

\[
D_{\mathrm{depth}}=D_{\mathrm{write}}+D_{\mathrm{prop}}.
\]

它是三个策略均值的**代数关系**，不是反馈、内容和幅度的独立因果贡献分解。第 2 轮用于预设曲线展示；不从三点形状选择一个最有利的趋势检验。不能由不显著推出相等，默认不提出等效声明，也不在见结果后选择等效界值。

沿用固定对应的主 pair-lDDT、次要逐残基 lDDT 与 TM-score。目标级配对 bootstrap 20,000 次，建议 seed `20260926`，同一组抽样用于所有策略及差值；区间条件于既有训练实例、旋转与面板。唯一主要量单列，其余区间明确为未统一校正的次要描述；不能任一曲线为正就将研究称为主要假说成功。

所有任务结束后统一评分；预测失败沿既定规则留在分母，主指标记零并报告失败来源，不裁剪链或换实例。确认面板分数不用于选择 checkpoint、策略、GPU 数值设置或追加条件。

## 5. 哪些结果会有信息，哪些推断仍不成立

| 观察 | 支持的有限判断 | 需要防止的误读 |
|---|---|---|
| all 的 Ψ 明显高于 first，直接差得到支持 | 对这些全轮训练模型，允许后续写入会增加交互 | 已唯一识别 recycle feedback，而不是写入次数／内容／时机的合并作用 |
| first-only 仍有正向 Ψ，且适配收益保留 | 后续重复写入不是在该固定设置观察交互的必要条件 | 已证明所有方向代价在第一轮完全形成 |
| last-only 仍有正向 Ψ | 适配写入后无需再经历另一个 recycle，也可观察交互 | 所有反馈或末轮内部非线性均无关 |
| first-only 的 Ψ 从 1→4 增加 | 单次写入后的冻结传播也能改变交互 | 跨轮求导或某个反馈组件已被确定为训练机制 |
| first-only 的 Ψ 接近零，四格也接近 Query | 稀疏部署下适配作用可能丢失 | 旋转被成功补偿、参数化更好或实现等效 |
| 区间宽、变化未建立 | 本矩阵未建立所测策略差异 | 已证明没有时序作用 |

尤其要展开四臂绝对变化：Ψ 下降可能源于 Native 掉分、Rotated 改善、G+ 变化或组合，不能只看 Ψ 的符号称为“有用缓解”。每轮记录残差相对现场 baseline 的 RMS、pair 状态变化，以及相对 Query 同轮预测的距离 RMS；这些量只作描述，不用真实结构 mask 决定注入或成为事后新预测器。

主设计不把四轮残差除以 4，也不把一次残差乘以 4。写入次数本来就是干预的一部分；强行匹配累计标量范数也不会使不同状态下的干预等价。幅度与时序的进一步拆分不在本轮承诺内。

## 6. 实施与验收顺序

1. **资产核对：**24 个原 checkpoint、三个 R、数据／特征、基座和源码 SHA；建立新的 proposal / execution lock，旧矩阵不覆盖。当前审阅的源码不必等于所有历史训练源码，执行前逐项区分并绑定。
2. **最小实现：**在独立 runner 中给每轮显式 `pass_id`，只门控首个 OPM 的完整适配残差。关闭时直接返回现场 baseline；其余 47 个 block、结构模块和全部回收状态照常计算。无需增量网络或新的可训练参数。
3. **观察器检查：**及时克隆坐标／mask，避免后续 in-place 运算改写快照；记录实际轮数和注入掩码。检查观察器有／无时四轮终点、RNG 与参数相同；不为记录中间值改动模型计算。
4. **两条 Dev 工程链：**四臂涵盖所有三个 R，检查零头／全关与 Query、all 与原路径、first 的首轮与 all 首轮、last 的前三轮与 Query、独立截停与前缀快照。保留原生数值容差依据，不根据正式分数放宽；身份和 mask 错误必须修复后再运行。
5. **完整预测：**同后端重新执行 all / first / last 与 Query。模型及特征可常驻，但每个 target / schedule 重置回收状态与预测 RNG；首实现不靠跨模型共享中间状态节省预算。保留全长输出、计算成本与失败记录。
6. **统一分析：**独立从 CIF 评分，重建逐目标 Ψ、策略直接差及上述恒等式；完整报告主要量、四格、种子／旋转与目标分布。图优先展示同一组四格均值及 Ψ 深度曲线，标注固定模型推理干预身份。

## 7. 第二阶段：推荐缩小为36组，按16并行估算

它问的是“允许重新适应各注入策略后，策略是否改变交互”，不能用第一阶段代答。但原末轮反传配方不支持 first-only；新增有效梯度规则后也不能将旧 all 当作完全匹配的训练对照。

建议三策略统一使用同一最终轮结构损失，保留所有原生可微 recycle 状态路径，冻结主干权重、关闭 dropout。原生离散距离分箱等不可微运算保持，不额外平滑；准确记录实际梯度经过的 MSA / pair 路径，不声称所有坐标反馈均可微。first-only 在中间轮不得 `no_grad`／detach 后续计算。禁止用仅第一轮损失或人为梯度旁路冒充相同终点训练。

activation checkpointing 的重算会重复调用 hook，**不能用全局调用次数判断 recycle 编号**；必须让重算恢复该图节点绑定的不可变 pass_id。先在固定 Train/Dev 链验证 final loss→首轮 writer 的有限非零梯度、冻结参数、恢复、完整最长训练长度及时间／显存，再讨论正式规模。

| 三策略都用相同新梯度规则 | 每策略 | 合计 |
|---|---:|---:|
| 完整三种子／三旋转四格 | 24 组 | **72 组** |
| 每组固定 1,536 更新 | 36,864 更新 | **110,592 更新** |
| 每组评测 Confirm96-B | 2,304 次 | **6,912 次**，Query 另计／核对复用 |

所以不是“只补 first、last 共 48 组”就完成公平训练比较。重新保留跨轮梯度也可能改变 FP32 路径与优化行为；旧 all 只能另列历史参考。需要新的共同 Train/Dev 校准、数值设置与成本预算，不按旧末轮反传的 1.7 小时／组直接承诺工期。

**缩减首选：减少旋转数，保留三种子、三时序与完整四格。**按原核心旋转编号最小者固定 `r20261001`，不依据历史效应强弱选择；它属于原稠密正交旋转族，不替换成 E1/E2 的保均值旋转。使用原三个配对训练种子，每组1,536步，Train96 / ESM2 / Confirm96-B保持。

| 注入策略 | F | RF | G+ | RG+ | 小计 |
|---|---:|---:|---:|---:|---:|
| First-only | 3 | 3 | 3 | 3 | 12 |
| Last-only | 3 | 3 | 3 | 3 | 12 |
| All | 3 | 3 | 3 | 3 | 12 |
| 合计 | 9 | 9 | 9 | 9 | **36** |

合计 **55,296 次更新、3,456 次适配模型预测**；若重做 Query，另96次。三策略从各臂相同初始化重新训练；All不能省略。同一可微依赖规则下，Last前三轮没有适配参数参与，可自然不形成那些轮次的反传图，不为形式一致而强造梯度。

重训练主要量保留 $D_{\mathrm{write}}^{(r20261001)}=\Psi_{\mathrm{all}}^{(r20261001)}-\Psi_{\mathrm{first}}^{(r20261001)}$，但这里的Ψ只对**一个旋转、三个种子**聚合，区别于第一阶段三旋转均值。Last比较预设次要。结论条件于该旋转，不能声称跨旋转一致性；原来三旋转的推理消融不补足新重训练矩阵的旋转覆盖。

### 16个H100单卡worker下的ETA

本轮重算的近期日志：原末轮反传E2重复9组平均4.1379秒／步、每组1.7269–1.8262小时；新校准9组普通续训平均4.0350秒／步。来源分别为 `engramfold/reports/e2_retraining_20260925/e2/formal/*/training.jsonl` 和 `engramfold/reports/posttraining_channel_calibration_20260925/remote_openfold/openfold/formal/*head_only/training.jsonl`。同校准目录2,592次Confirm96预测均时2.5729秒。这些是模型阶段记录，不含所有加载与工程成本。

**跨轮训练尚未实测。**保守预算：First和All每组3.5–5小时，Last每组1.8–2.2小时。旧路径约为$4F+B$，前两类新路径约为$4F+4B$，B含checkpoint重算；不能把旧总时间直接乘4。具体倍率、最长训练链显存和恢复正确性仍需工程检查。

36组可按12个worker承接24个长任务、4个worker承接12个短任务安排，并按实际完成时间补位：

\[
T_{\mathrm{train}}\approx\max\{2t_{\mathrm{long}},3t_{\mathrm{short}}\}
\approx\mathbf{7\text{–}10\ h}.
\]

对应训练预算约106–146 H100卡时。**训练加配套评测／汇总约8–12小时；工程接通顺利、共同Train/Dev校准受限时，端到端先预留10–16小时，排队另算。**当前本账号HPC3队列为空，acd_u启用；这不是已经预留16张H100。估算以16个worker持续可用为前提。

## 8. 决策建议

固定模型推理回答“现有交互在部署时依赖何种注入时序”；更新后的36组重训练回答“允许适应各策略后，同一旋转下的交互是否改变”。可以分别推进，不把第一项设为第二项必须阳性的前提。二者与已经完成的anchor来源实验各有范围，均不自动提供普遍适配器选择规则。
