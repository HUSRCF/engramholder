\section{Native update construction and orientation controls}
\label{sec:construction}
\subsection{Query-anchored residual adaptation}
\label{sec:residual}
Let $e(x)$ be frozen sequence features and $f_\theta$ a shared trainable predictor
of residue-level factor increments. At interface $k$ and recycle $t$, let
$a_{k,t},b_{k,t}$ denote the native factors, $G_{k,t}$ the frozen pair-generating
operator, and $U_{k,t,0}$ its native baseline update at the selected interface.
This is an update, not the full pair state or a common query-only trajectory:
OpenFold computes it on each arm's current state, while Protenix reuses its
cached query update. We define
\begin{align}
 (\delta a,\delta b)&=f_\theta(e(x)),\label{eq:increments}\\
 \Delta U_{k,t}&=G_{k,t}(a_{k,t}+\delta a,b_{k,t}+\delta b)
               -G_{k,t}(a_{k,t},b_{k,t}),\label{eq:residual}\\
 U^{(R)}_{k,t}&=U_{k,t,0}+\mathcal R_k\Delta U_{k,t}.\label{eq:injection}
\end{align}
The last predictor affine layer has zero weights and bias, giving zero residual
and exactly the unadapted initial function. The sequence encoder remains
nonzero. Only the adapter is optimized; gradients propagate through the frozen
folding model. Query factors provide the composition anchors, rather than
structure labels as predictor inputs.

The operator is backbone-specific. Protenix reuses cached query anchors and
the same update across passes within a prediction. OpenFold's first main
Evoformer OPM reads live MSA/pair states shaped by adapted recycle history.
AtlasFold's first LM difference/product hook reads the current pass's
MLM-dependent features before fusion with recycled states; its anchor does
not directly read adapted history. Figure~\ref{fig:construction} summarizes
the intervention.

\subsection{Full and first-order factor updates}
\label{sec:full_tangent}
For Protenix's bilinear decoder, write
\begin{equation}
 G_D(a,b)_{ij}=\frac{D W\operatorname{vec}(a_i\otimes b_j)+b_{\rm out}}{D+\epsilon},
 \qquad \widetilde W=\frac{D}{D+\epsilon}W.
\end{equation}
The full residual is
\begin{equation}
 \Delta U^{\rm full}_{ij}=\widetilde W\operatorname{vec}
 (\delta a_i\otimes b_{q,j}+a_{q,i}\otimes\delta b_j+
 \delta a_i\otimes\delta b_j).
 \label{eq:full}
\end{equation}
The first-order, or tangent, construction omits the final quadratic term while
keeping the same predictor and parameter count. The output bias cancels.
We use $\epsilon=10^{-3}$ and the historical training-side scale $D=508.5$, the
median MSA depth in the original Train24 cache. Subsequent experiments retain
this constant. The original depth-one query update remains the baseline;
$U_q$ is not replaced by $G_D(a_q,b_q)$. OpenFold retains its own mask and
effective-row normalization; AtlasFold has no OPM depth constant
(Appendix~\ref{app:operators}).

\subsection{Fixed orthogonal output controls}
\label{sec:rotation}
For a pair-channel column vector,
$(\mathcal R\Delta U)_{ij}=R\Delta U_{ij}$ with $R^\top R=I$.
A single fixed matrix acts across all residue pairs, rotating only the residual,
not the baseline update or protein-coordinate axes. Labels are identical across
arms. Native uses $R=I$. Each rotated adapter
starts from zero residual and receives task training, so the experiment does
not perturb an already trained native adapter at inference time.
Within the same head at matched factors and parameters, orthogonality preserves residual norms,
decoder singular values and the local writer's $J^\top J$. It need not preserve
its composition with the frozen downstream Jacobian, AdamW dynamics, or norms
of the different updates learned after training. For state-dependent anchors,
this is a local control, not a spectral equivalence of the whole recycled model.

\subsection{A generic head that can absorb the rotation}
\label{sec:generic}
G+ uses the same sequence-encoder architecture and explicitly receives the corresponding
query factors. Its pair input concatenates projected node features $z_i,z_j$,
$a_i,b_j$, and clipped relative sequence position. A pair MLP ends in a free
affine layer and produces a zero-initialized residual. Unlike the earlier
Generic control, G+ has explicit factor access.
For $\Delta U_G=Wh_\phi+b$ and
$\Delta U_{G,R}=R(W_Rh_\phi+b_R)$, the choice
\begin{equation}
 W_R=R^\top W,\qquad b_R=R^\top b
 \quad\Longrightarrow\quad \mathcal F_G^R=\mathcal F_G
 \label{eq:absorb}
\end{equation}
absorbs the rotation. This proves rotation invariance of G+'s own function
class, not $\mathcal F_{\rm Factor}\subseteq\mathcal F_{G+}$. G+ is not
a proven performance or expressivity upper bound. The heads also differ in
residue-versus-pair organization, nonlinearities and anchor entry points. The
fixed factor decoder has no corresponding general absorption guarantee. Equation~\ref{eq:absorb} concerns representable functions: coordinate-wise
second moments can still make AdamW sensitive to the reparameterization.
We therefore measure both heads' rotation effects rather than require G+'s
effect to be zero. Factor and G+ have similar, not identical, sizes: 373,824
versus 378,144 trainable parameters for Protenix and OpenFold with ESM2 inputs.
The ESMC follow-up changes only the input projection width within each head
(Appendix~\ref{app:esmc}).
